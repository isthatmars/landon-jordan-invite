# Landon & Jordan's 80s Birthday Invite

Interactive neon synthwave invitation site (Next.js App Router + Tailwind + Framer Motion).

## Scripts
```bash
npm install
npm run dev    # http://localhost:3000
npm run build
npm start
```

## Highlights
- Full-viewport hero with HTML typography over a generated photo
- Cassette mixtape player, CRT video browser, Pac-Man + pinball
- RSVP form with abandoned-draft hooks (mock store, Supabase-ready)
- Neon `/admin` (access code) — CMS, RSVPs, media, email/SMS composers, reminders

## Admin
- Visit `/admin`
- Default code: `NEON80S` (`ADMIN_ACCESS_CODE`)
- Notifications are **email-first**; SMS is optional/pluggable (no A2P required)

See Project store docs: `edit-guide.md`, `admin-guide.md`, `notifications-plan.md`.
